PAPlanner

Progress-Aware Planner for Embodiment-Agnostic Vision-and-Language Navigation

📄 Paper PDF 💻 Code

Abstract

Vision-and-language navigation in continuous environments (VLN-CE) has achieved remarkable progress with the integration of vision-language models (VLMs). However, when following long-horizon instructions, VLM-based navigation faces a key challenge: the reliance on implicit temporal reasoning often leads to unreliable estimation of instruction execution progress. To address this issue, we propose PAPlanner, a progress-aware planning framework for VLN-CE. PAPlanner first formulates navigation as a progress-aware planning problem by decomposing each instruction into ordered sub-instructions. Then, the VLM explicitly tracks the execution progress while predicting navigation commands within a structured action space, which significantly enhances the reasoning stability. Finally, PAPlanner executes such commands through a locomotion policy that combines real-time traversability estimation with classical local planning. By decoupling semantic reasoning from motion execution, PAPlanner achieves embodiment-agnostic deployment and enables safe navigation without retraining. Extensive experiments on R2R-CE and RxR-CE benchmarks, as well as real-world deployments on humanoid, quadruped, and wheeled robots, demonstrate that PAPlanner achieves superior generalization in unseen environments and robust sim-to-real transfer.
